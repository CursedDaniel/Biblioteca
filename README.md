# **Biblioteca**

Sistema para la gestión de **préstamos de material académico y libros** de una biblioteca.

## **Integrantes**

1. **Daniel Londoño Ramirez**
2. **Esteban Triana Galindo**

## **Descripción**

En este proyecto se desarrolla un sistema para administrar:

* **Préstamos y multas** de los usuarios.
* **Información de libros y su inventario**.
* **Autores, categorías y editoriales**.
* **Ejemplares** disponibles en la biblioteca.

El sistema está desarrollado en **Python** y utiliza una estructura organizada mediante **entidades y operaciones CRUD**.

## **Instalación**

Se requiere tener instalado **Python 3**.

Después de clonar el repositorio, ejecutar:

```text
setup.bat
```

El archivo **`setup.bat`** crea el entorno virtual, instala las dependencias y ejecuta el programa.
