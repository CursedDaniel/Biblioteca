# Biblioteca  
Sistema para prestamos de material academico y libros de una biblioteca  
Integrantes:  
1 - Daniel londoño Ramirez  
2 - Esteban Triana Galindo  
en este proyecto se llevara a cabo un sistema que administra  
los prestamos y multas de los usuarios de una biblioteca  
ademas de poder manejar la informacion de los libros y su inventario  
con busquedas en bases de datos relacionales
